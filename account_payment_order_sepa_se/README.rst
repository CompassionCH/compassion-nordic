This module adapts SEPA payment order generation for Swedish banks
(notably SEB).

It adjusts the generated PAIN XML for Swedish requirements, including
Bankgiro/non-IBAN account handling and parser-compatible initiating
party data.

It also uses payment communication as journal entry label to ease
reconciliation.
