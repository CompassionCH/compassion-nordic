Compassion Nordic Disbursement View
===================================

This module provides a custom view for disbursements in Odoo. It is
designed to enhance the user interface for managing and viewing
disbursement records, tailored to the specific needs of Compassion
Nordic operations.

Features
--------

- Customized tree and form views for disbursement records.
- Improved filtering and searching capabilities.
- User-friendly layout for better data visualization.
